# LING OS 版本号与功能规范（正式文件）

> 版本：v1（2026-10-30）
> 状态：规范基线；未部署、未提交发布
> 作用：统一版本号、命名、edition、功能矩阵、发布标准与安全等级对应关系，
>       后续所有构建、Release、文档、安装器、WebUI 必须遵守本文件。

---

## 1. 版本号规则

采用「适配 SemVer」：

    MAJOR.MINOR.PATCH

- MAJOR：不兼容的大版本（1.0 起启用；0.x 阶段表示开发期）
- MINOR：新增功能、新 edition、新安全等级能力（向后兼容）
- PATCH：修复、文档、构建/安装修复（不改功能契约）

预发布后缀：

    -alpha.N / -beta.N / -rc.N

构建元数据（只写内部文件，不写文件名）：

    +build.YYYYMMDD.git

Tag 规范：v + 版本号，如 v0.10.0、v0.10.1-rc.1。

版本示例：
- 0.9.15：安装器/桌面收尾
- 0.10.0：安全与隐私基线（L0–L4、本地配置）
- 0.10.1：0.10.0 的修复补丁
- 0.11.0：可信启动 + AI 身份
- 1.0.0：首个稳定版（API/配置 schema 冻结）

规则：
1. 功能变更必须 MINOR 及以上，修复才用 PATCH；
2. 任何影响安装/桌面/安全默认值的行为变更必须写升级说明；
3. 配置文件 schema 带版本号，升级必须迁移并保留回滚；
4. 内部版本文件 /etc/lingos-version 永远包含：version、edition、arch、git、build_ts、kcmdline。

## 2. 命名规范

### 2.1 镜像文件

    LINGOS_<arch>_<version>_<edition>.iso

- arch：arm64 / x86_64
- version：0.10.0 等
- edition：server / desktop / system / bin（定义见第 3 节）
- 超过 GitHub 2GiB 单资产限制时分片：.part0 / .part1 ...
- 校验：SHA256SUMS.txt
- 合并说明：<basename>.合并说明.txt（统一后缀，不再使用 .iso.txt）

示例：

    LINGOS_arm64_0.10.0_desktop.iso
    LINGOS_arm64_0.10.0_desktop.iso.part0
    LINGOS_x86_64_0.10.0_server.iso
    LINGOS_arm64_0.10.0_setup.iso（网络安装器）

### 2.2 内部展示

- GRUB 菜单：LING OS 0.10.0（desktop）
- 安装器标题：LING OS 0.10.0 安装器 - desktop
- 桌面/waybar：LING OS 0.10.0
- WebUI：页脚 + /api/version
- 错误/日志：版本号 + build 信息
- /etc/lingos-version 示例：

    {"version":"0.10.0","edition":"desktop","arch":"arm64","git":"abc1234","build_ts":"2026-10-30T12:00:00Z"}

### 2.3 其他命名

- Release tag：v0.10.0
- Release 标题：LING OS v0.10.0（含 edition 说明在正文）
- 容器镜像：lingos:<version>-<edition>
- 文档：LINGOS-<version>-<主题>.md

## 5. 发布标准（每个版本必须满足）

1. 双架构（arm64/x86_64）ISO 构建成功，启动冒烟 PASS；
2. Vectras arm64 真机安装到桌面（或对应 edition 目标）通过；
3. 版本号/edition 全链路显示正确；
4. 安全等级默认值符合本规范，且「安全设置仅本地修改」生效；
5. 安装器日志/错误终端/恢复路径可用；
6. 文档齐全：变更日志、升级说明、安全说明、功能矩阵、测试报告；
7. 制品有 SHA256SUMS + 合并说明（如分片）+ 签名（0.11 起）；
8. Release 正文列出：新增、变更、修复、已知问题、回滚方法。

## 6. 安全等级与版本的关系

| 版本 | L0 | L1 | L2 | L3 | L4 | Custom |
|---|---|---|---|---|---|---|
| 0.9.x | 部分 | 部分 | 否 | 否 | 否 | 否 |
| 0.10.0 | 是 | 是（默认） | 是 | 基础 | 基础 | 是 |
| 0.11.0 | 是 | 是 | 是 | 完善 | 完善 | 是 |
| 0.12.0+ | 是 | 是 | 是 | 完整 | 完整 | 是 |

规则：
- L4 默认关闭，开启需用户主动确认；
- L0/L1 可作为兼容模式，但不得静默降低安全等级；
- 任何版本不得默认关闭「安全设置本地修改」约束。

## 7. 兼容性与弃用政策

1. 0.x 阶段：功能与 schema 可变，但必须写迁移说明；
2. 1.0 起：CLI/API/配置 schema 遵守语义化版本；破坏性变更进 MAJOR；
3. 弃用：至少提前一个 MINOR 标记，文档给出替代方案；
4. 配置迁移：旧配置自动升级 + 备份 + 回滚；
5. edition 间迁移：server → desktop/system 允许；降级需明确提示。

---

## 8. 分支、构建与制品

- main：受保护，CI 必须通过；
- release/<version>：发布分支，只接受 PATCH 修复；
- tag：v<version>；
- 制品：ISO（分片）、SHA256SUMS、合并说明、SBOM（0.11+）、签名（0.11+）；
- 构建环境固定（容器/runner 镜像版本记录）；
- 可复现构建目标 0.11 达成。

---

## 9. 文档要求（随版本发布）

1. CHANGELOG（按 Added/Changed/Fixed/Security）
2. 升级说明（含回滚）
3. 安全说明（等级默认值、已知风险、CVE 处理）
4. 功能矩阵（本文件更新）
5. 测试报告（启动/安装/桌面/安全/隐私）
6. 用户指南（安装、VNC 兜底、日志获取、隐私设置）
