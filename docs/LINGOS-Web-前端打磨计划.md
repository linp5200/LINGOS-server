# LING OS Web 前端打磨计划（CI 前）

> 2026-11-14 · 结论：**现在不能推 CI**。功能通了，但"能用"和"经得起验收"之间还差一轮系统打磨。
> 本文件是发 CI 前的计划与验收基线；每做完一批更新状态。

## 一、现状（已落地）

- `webdesk/` 已换成新前端（旧版留档 `webdesk-legacy-0.13/`），8080 同源，登录 + 首次初始化可用。
- 七个视图接真实接口：家、设备、文件、安全、AI、系统、设置。
- 未接后端 → `err-noserver`（实测）；命令服务未起 → 明确 502 提示（实测）。
- 手机竖屏 / 电脑横屏自动切换（实测 390 / 1024）。
- 已用 Playwright 实测：登录、开灯命令、文件写入/列表、AI 真实报错、err-noserver、双版布局。

## 二、缺口（按优先级）

### P0 · 不修不能发

| # | 缺口 | 改法 | 验收 |
|---|---|---|---|
| P0-1 | 系统页不探测命令服务状态，常显「未检查」 | 进页面自动探一次 `system.status`，显示在线/离线 + 时间 | 离线时显示「未连」且不重试风暴；在线时显示版本 |
| P0-2 | 命令按钮执行中可连点，无 loading | 执行时按钮 disabled + 「执行中」，结果回填 | 连点 3 次只发 1 个请求 |
| P0-3 | 设备命令失败后界面不回滚 | 失败保留原状态 + 错误条；成功才更新 | 模拟 502 时卡面不变成功 |
| P0-4 | 传感器/摄像头状态映射太窄 | 覆盖 temperature/humidity/smoke/motion/stream 等字段 | 5 类设备各一条真实数据 |
| P0-5 | 设备「发现」只 toast 数量，不展示结果 | 列出发现结果，可逐条添加 | `/api/devices/discover` 返回可点列表 |
| P0-6 | 401 只在启动时处理，会话过期后页面卡死 | 任意接口 401 → 回登录页并提示「会话过期」 | 手动删 cookie 后点任意操作回登录 |
| P0-7 | 没有请求超时，后端挂起时按钮转圈不动 | fetch 8s 超时 → 统一「后台没回话」 | 停后端后操作 8s 内出提示 |
| P0-8 | 安全页权限/行为/输入/ACL 入口缺 | 加 ACL 编辑（带 root key）、权限清单、规则开关 | 命令服务离线时显示明确说明而非空白 |
| P0-9 | 旧入口 `debug.html` / `files.html` 与新版并存且风格旧 | 加「旧版」提示条，或重定向到新前端对应视图 | 打开两页不误导 |
| P0-10 | 文件页无面包屑、无排序、删除无二次确认（有 confirm 但文案粗糙） | 面包屑路径、按名/时间排序、删除确认写清后果 | 三层目录可回退 |
| P0-11 | 登录/初始化错误不分类 | 401/403/409/网络分别给话术；密码强度提示 | 错密码、缺配对码、重复初始化各一条提示 |
| P0-12 | PWA 缺失（manifest 未引用、无图标） | 引 manifest、补图标、theme-color 跟随主题 | 手机「添加到主屏幕」可用 |

### P1 · 发 CI 前尽量做

- 断点全量：320 / 390 / 768 / 1024 / 1440 / 1920，全部无横向溢出、无遮挡。
- 暗色全页走查（家/设备/文件/安全/AI/系统/设置）。
- 空态 / 骨架 / 错误态三件套每页齐全。
- 文案：术语统一（设备/防线/等级/命令服务），不出现英文占位。
- 键盘：Tab 顺序、Esc 关确认、焦点归还、focus-visible。
- 对比度：正文 ≥4.5:1，按钮/标签实测。
- 动效：只保留 120–220ms 的反馈，无无限循环动画。

### P2 · 下一版本

- 摄像头真实接入（RTSP → `state.stream`，预览可钉在首页）。
- AI 技能库 / 模型 Provider / 记忆浏览（`skill.*`、`data.*`）。
- 场景与自动化（`rules.*`、`home.*`）。
- 通知与语音（`notify.*`、`voice.*`）。
- 天气小卡（`weather.*`）。

## 四、CI 门槛（全部满足才发）

1. `node --check assets/app.js`、HTML 标签闭合、无重复 id、资源存在。
2. Playwright 验收脚本全绿：登录 → 七视图 → 开灯 → 开锁确认 → 文件读写 → AI 发送 → 502 提示 → err-noserver。
3. 断点矩阵截图归档（320/390/768/1024/1440），无横向溢出、无遮挡。
4. 控制台零 error（允许 401 首次探测一条）。
5. 已知缺口清单清零或明确降级为 P2 并在文档标注。
6. 仓库只含计划内改动；旧 webdesk 留档不删。

## 六、风险

- 本机没有 C 核心（18080），系统命令全部 502；验收只验证「离线提示正确」，不验证真实命令结果。
- 没有真机 Termux，PWA/安全区/软键盘无法真机验证。
- AI 依赖 `run/ai.sock`，本机无模型后端，只验证「如实报错」。
