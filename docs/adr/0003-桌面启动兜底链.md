# ADR 0003：桌面启动兜底链（Wayland → X11 → Xvfb+VNC → 文本）

- 状态：Accepted
- 日期：2026-10-30
- 关联版本：0.9.15
- 决策者：Lead

## 背景与问题

Vectras/部分虚拟化环境只提供 simple-framebuffer（无 KMS），labwc/Wayland 无法启动，
桌面表现为“无信号”；用户需要在无图形驱动时仍能访问系统。

## 可选方案

1. 仅支持 Wayland —— 无 KMS 环境不可用。
2. 强制 X11 —— 兼容性更好，但放弃 Wayland 现代栈。
3. 启动时逐级降级：Wayland → X11 → Xvfb+VNC → 文本。
4. 直接默认 VNC —— 体验差且把远程暴露作为默认。

## 决策

采用方案 3，VNC 仅在更高级失败后启动，并明确提示与随机密码。

- 启动器 lingos-desktop-launch 负责探测/降级；
- X11 使用 fbdev；仍失败则 Xvfb + x11vnc（软件渲染）；
- 终端与串口打印局域网 VNC 地址 + 随机密码，并写共享文件夹 lingos-vnc.txt；
- 支持内核参数 lingos.session=wayland|x11|vnc|text、lingos.desktop=0、lingos.vnc=1；
- GRUB 提供文本/X11/详细日志启动项。

## 影响

- 新增依赖 xvfb/x11vnc/openbox/xterm；
- 安全：VNC 默认仅局域网、随机密码、可关闭；公网需 VPN/SSH 隧道；
- 运维：无头设备可远程访问；
- 测试：需覆盖四条路径。
