# ADR 0001：安全/隐私设置仅允许本地控制台修改

- 状态：Accepted
- 日期：2026-10-30
- 关联版本：0.10.0
- 决策者：Lead（用户授权）

## 背景与问题

安全/隐私设置如果可被局域网 WebUI/App/API、VNC、SSH 或自动化脚本修改，
攻击者可在用户不知情时降低防护（例如关闭防火墙、开启云 AI、放宽权限）。
同时，模拟点击/自动化工具可能伪造用户操作。

## 可选方案

1. 所有通道都可修改，但需要密码 —— 仍可被 CSRF/会话劫持/自动化绕过。
2. 仅本地桌面可修改，远程只读 —— 简单；但需要定义“本地”。
3. 本地控制台 + 再认证 + 键入确认短语 + 可选 FIDO2 —— 更强，体验稍重。
4. 硬件密钥/TPM 封印 —— 最强，但多数设备无 TPM。

## 决策

采用方案 3，并保留方案 4 作为可选增强（TPM 可用时）。

- 唯一入口：本地 seat0 会话（tty/wayland/x11，Session.Remote=no）运行的安全设置应用；
- 服务端强制：安全策略写入只接受本机特定 Unix socket + 本地会话凭据；
- 远程通道（WebUI/App/VNC/SSH/API/自动化）一律只读；修改请求返回 403 与错误码 70002，并写审计；
- 再认证：本地密码 + 可选 FIDO2/声纹辅助；L2+ 修改需键入确认短语；
- 输入注入防护：安全设置窗口禁止 XTEST/uinput/ydotool/RemoteDesktop portal 注入；
- 策略文件签名/哈希，仅本地特权守护进程可写；回滚需本地恢复模式。

## 影响

- 代码：权限服务、HTTP/WS 鉴权、审计、恢复模式；
- 接口：/api/v1/security 仅本地；远程只读；
- 运维：远程排障只能看状态，修改需到设备前；
- 安全：显著降低远程降级风险；
- 版本：0.10.0 必须实现，之后版本不得默认关闭。

## 后续动作
