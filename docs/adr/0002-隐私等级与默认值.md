# ADR 0002：隐私等级 L0–L4、Custom 模式与默认值

- 状态：Accepted
- 日期：2026-10-30
- 关联版本：0.10.0
- 决策者：Lead（用户授权）

## 背景与问题

隐私/安全增强项如果由系统替用户决定，可能导致网站/应用不可用且用户不知原因；
若全部默认最严，会破坏可用性；若默认最松，则隐私不足。
用户要求：所有可选开关可配置、提供自定义模式、新增 L4(MAX) 全拒绝档。

## 可选方案

1. 单一“隐私模式”开/关（现状）—— 粒度不足。
2. 固定三档（低/中/高）—— 仍无法覆盖极端场景。
3. L0–L4 五档 + Custom 自定义 —— 覆盖广，但 UI/测试成本高。
4. 只提供 Custom —— 灵活但对普通用户不友好。

## 决策

采用方案 3。

- L0 兼容、L1 增强（默认）、L2 严格、L3 极端、L4(MAX) 全拒绝；
- Custom：逐项/按应用/按网站/仅本次/本次会话/永久；
- 每项必须显示“影响哪些网站/应用/功能 + 如何恢复”；
- L4：默认无出站、无后台同步/遥测/云 AI/VNC；所有获取需用户手动确认并指定范围；未授权=禁止；
- 兼容性诊断 + 单点放宽；
- 所有切换写审计；L2+ 需本地确认。

## 影响

- 配置 schema 增加 privacy_level 与 feature flags；
- 安全服务需要策略引擎（网络/位置/设备/来源/工具/插件）；
- UI：隐私仪表盘 + 兼容性提示；
- 测试：L0–L4 矩阵（网络/权限/位置/工具/插件）。

## 后续动作

- S2（等级+审计）、S25（选项清单/Custom）、S28（L4 deny-all+审批中心）、S29（兼容性诊断）；
- 文档：用户隐私指南、默认值表；
- 默认 L1，L4 需主动开启并确认。
