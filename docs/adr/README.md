# ADR（Architecture Decision Record）

本目录记录重大架构/安全/接口决策。每个决策一个文件，命名 NNNN-短标题.md。

## 状态
- Proposed（提议）
- Accepted（接受）
- Superseded（被取代）
- Deprecated（废弃）

## 模板

    标题：NNNN-决策标题
    状态：Proposed/Accepted/Superseded/Deprecated
    日期：YYYY-MM-DD
    决策者：
    关联版本：

    ## 背景与问题
    ## 可选方案
    ## 决策
    ## 影响（代码/接口/运维/安全/版本）
    ## 后续动作
