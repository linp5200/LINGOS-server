# LING OS · 组件状态与规范（0.15）

> token 单一事实源：`webdesk/assets/tokens.json`（DTCG），产物 `tokens.css` 由 `scripts/build-tokens.py` 生成，禁止手改。
> 组件集中在 `webdesk/assets/app.js` 的 render 函数；本文定义必须覆盖的状态与尺寸。

## 1. 通用规则

- 触控：移动端 ≥44×44；桌面最小 24×24（WCAG 2.2）。
- 焦点：`:focus-visible` 2px 环，与未聚焦对比 ≥3:1；不裁切。
- 过渡：只动 `transform/opacity`；hover 120ms，按压 90ms。
- 文案：按钮 = 动词 + 对象（“保存设置”“删除设备”），不写“确定”。
- 关闭：`prefers-reduced-motion` / 动效关闭时，所有动画压到 0.01ms，功能不变。

## 2. 状态矩阵

| 组件 | default | hover | focus-visible | active | disabled | loading | error | selected |
|---|---|---|---|---|---|---|---|---|

| 图标按钮 `.icon-btn` | 36–44 方块 | 底色抬升 | 2px 环 | scale .985 | 同按钮 | spinner | — | `aria-pressed` |
| 输入 `.field input` | 1px 边 | — | 2px 环 | — | 只读样式 | — | 红边 + 字段下错误 | — |
| 开关 `.switch` | 灰轨 | 轨加深 | 2px 环 | 拇指滑动 100ms | 禁用 + 原因 | — | — | 绿轨 + `aria-checked` |

## 3. 尺寸与间距

- 间距阶梯：4/8/12/16/24/32（8pt 为主，4 为半格）。
- 圆角：8/12/16/999。
- 字阶：11/11.5/12/12.5/13/13.5/14/15/21/24/28；正文 13–14。
- 行宽：说明文字 ≤60ch；设置内容区 ≤520–620px。

## 4. 反馈选择

| 场景 | 组件 |
|---|---|
| 轻量成功 | toast（2.6s，可点关） |
| 错误 | toast `err` 或字段行内；`role=alert` |
| 页面级失败 | banner + 重试 |
| 破坏性 | 确认条/模态，主动作写对象，危险色 |
| 需要阅读 | 模态（焦点陷阱、Esc、inert、焦点归还） |
| 未知等待 | 骨架/spinner；不造假进度 |

## 5. 验收脚本

```bash
python3 scripts/build-tokens.py                      # token 一致性
BASE=http://127.0.0.1:8080 node tests/ui_check.mjs   # 对比度/触控/溢出（日间）
DARK=1 BASE=http://127.0.0.1:8080 node tests/ui_check.mjs  # 夜间
```

- 对比度：正文 ≥4.5:1，大字 ≥3:1。
- 触控：移动端 <40px 的按钮会被列出。
- 溢出：`scrollWidth > innerWidth` 即失败。
