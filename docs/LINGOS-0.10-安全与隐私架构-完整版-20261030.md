## 0. 文档说明

- 目标：把 LING OS 从"有安全功能"升级为"**默认安全、默认隐私、可验证、可恢复**"的操作系统。
- 对标：GrapheneOS（极端隐私/安全）、Windows（安装/恢复/安全中心）、ChromeOS（可验证启动）、
  Fedora Silverblue（原子更新）、macOS/iOS（权限与加密）、Qubes（隔离）、Tails/Whonix（匿名）、
  OpenBSD（系统加固）、Signal（通信加密）、NIST/ISO（合规框架）。
- 原则：**借鉴理念与接口，不直接照搬代码**；受硬件限制的能力（TPM、Secure Boot 自定义密钥、
  MTE）做"可用则启用、不可用则显式降级并告知"。

## 1. 目标与范围

### 1.1 目标
1. 设备丢失/被盗：数据不可读（全盘加密）、可远程/本地安全擦除。
2. 恶意应用：无法越权访问文件/摄像头/麦克风/网络/其他应用数据。
3. 网络攻击：默认拒绝入站、出站可控、DNS 加密、VPN/Tor 可选且防泄漏。
4. 供应链攻击：镜像/更新签名校验、可复现构建、SBOM、防回滚。
5. AI 隐私：语音、视觉、记忆、对话默认本地处理；云端调用需显式授权；生物特征模板加密。
6. 平台可信：启动链可验证、系统分区只读、完整性被破坏可检测/可恢复。
7. 用户可控：权限面板、隐私仪表盘、审计日志、危险操作二次确认。
8. 生命线优先：安全告警不可静默失败（与 alertd"预警=生命线"一致）。

### 1.2 范围
- 覆盖：0.10.0 起的全部 ISO（server / desktop / system / bin）、安装器、首启、桌面、WebUI、AI 服务、更新系统。
- 不覆盖：Android 宿主/Vectras 本身、物理硬件固件漏洞、用户主动泄露。

## 2. 威胁模型

### 2.1 资产
| 资产 | 说明 |
|---|---|
| 用户数据 | 文档、照片、聊天、记忆库、语音/视觉数据 |
| 凭据 | 密码、API Key、SSH/Token、VNC 密码、AI Provider Key |
| 生物特征 | 声纹模板、人脸特征（如启用） |
| 系统完整性 | 引导链、内核、系统分区、更新包 |
| 设备标识 | 主机名、MAC、序列号、网络指纹 |
| 生命线告警 | 健康/安全告警数据与通知链路 |

### 2.2 对手
1. 恶意/越权应用（应用商店、侧载、插件）。
2. 局域网攻击者（ARP/DNS 欺骗、VNC 暴露、弱口令）。
3. 物理接触者（丢失、被盗、检查站、取证）。
4. 供应链攻击者（镜像、更新、依赖包）。
5. 云服务/模型提供方（数据外泄、训练滥用）。
6. 内部误用（AI 越权调用、日志泄露）。

### 2.3 信任边界
- 可信：签名验证通过的引导链、只读系统分区、内核、LING OS 安全守护进程。
- 半可信：桌面应用（沙箱内）、AI 技能（权限闸门内）、第三方 Provider。
- 不可信：网络、USB 外设、共享文件夹、VNC 客户端、宿主 Android。

### 2.4 假设与硬件限制
- ARM64 Vectras/普通 QEMU：通常**无 TPM、无自定义 Secure Boot 密钥、无 MTE**；
  → 启动验证采用 dm-verity + 签名 GRUB/内核（软件信任根），并显式标注"硬件信任根缺失"。
- 真机若有 TPM 2.0/fTPM：启用 measured boot + LUKS2 TPM 解锁 + 远程证明（可选）。
- TCG 模拟性能有限：加密参数选择适中（Argon2id 时间成本可配置），避免首启过慢。

## 3. 设计原则（10 条）

1. **默认安全**：安装即加密、默认拒绝入站、服务最小权限。
2. **默认隐私**：遥测默认关闭、AI 默认本地、数据最小化、不要求账号。
3. **最小权限**：应用/技能/服务按需授权，权限可随时撤销。
4. **纵深防御**：启动链、内核、沙箱、网络、审计多层独立。
5. **可验证**：签名、哈希链、完整性状态用户可见。
6. **失效安全（安全侧）**：安全组件失败→拒绝执行；但**生命线告警失败必须显式上报**，不得静默。
7. **可恢复**：任何安全配置错误都有恢复模式/救援路径。
8. **透明可控**：隐私仪表盘展示"谁在何时访问了什么"。
9. **最小惊讶**：危险开关必须二次确认并说明后果（沿用 WebUI 现有确认机制）。
10. **渐进增强**：硬件能力缺失时降级运行并明确告知，不假装安全。

## 5. 隐私等级 L0–L3（核心产品化设计）

沿用并扩展现有 `options_apply_privacy_mode()`（一次开启全部安全/隐私项），升级为**四级**：

| 等级 | 名称 | 默认行为 | 适用 |
|---|---|---|---|
| L0 | 兼容 | 功能优先，遥测关闭，基础防火墙 | 初次体验 |
| L1 | 增强（默认） | 全盘加密、应用沙箱、DoH、MAC 随机化、权限提示 | 日常 |
| L2 | 严格 | 禁止未知应用联网、传感器默认关、剪贴板自动清空、锁屏隐藏通知、AI 仅本地 | 敏感用户 |
| L3 | 极端（GrapheneOS 风格） | 出站默认拒绝（白名单）、VPN/Tor 强制、传感器硬件级关闭、USB 锁定、自动重启、胁迫密码/快速擦除、截图/录屏保护 | 高风险场景 |
| **L4** | **MAX（最高）** | **默认全拒绝：无出站网络、无后台同步、无遥测、无云 AI、无 VNC/远程；所有数据获取（应用/网站/系统）必须用户手动确认，且由用户手动指定可获取范围；未授权范围一律禁止** | 最高敏感/离线使用 |

规则：
- 等级切换必须列出"将要改变的项目"并二次确认。
- L3 下若网络不可用，提供**离线模式**并明确提示，而不是悄悄降级。
- 每个等级对应 `/etc/lingos/privacy-level.json`，安装器/首启可选择。
- 所有等级变更写入审计日志（哈希链）。
- **所有隐私/安全增强项都是可选开关**：不属于"我们替用户决定"；每个开关必须显示"可能影响哪些网站/应用/功能"与"如何恢复"。
- 提供**自定义模式（Custom）**：用户逐项选择隐藏/允许/按应用/按网站/一次性/永久（详见 6.14）。
- **安全/隐私设置只能由用户在本地硬件控制台修改**；WebUI/App/VNC/SSH/API 等远程通道一律只读（详见 6.14.5）。
- 新增 **L4 (MAX)** 最高保护档（详见 6.14.4）。

## 6. 安全子系统设计

### 6.1 启动与固件安全
- 签名 GRUB + 签名内核/initramfs（自建密钥，安装器生成/内置公钥）。
- **dm-verity** 保护只读系统分区（squashfs/ext4 ro），启动时校验；损坏→恢复模式。
- A/B 双分区 + RAUC 原子更新 + 自动回滚 + 防降级（rollback protection）。
- 恢复模式（recovery）与救援 shell；安全启动失败时进入可诊断状态而非黑屏。
- TPM 2.0（若可用）：measured boot、LUKS2 自动解锁、远程证明（可选）；不可用时显式提示。
- UEFI 安全启动：提供签名 chain，说明普通设备需手动导入密钥；Vectras 默认不启用。

### 6.2 内核与系统加固
- 内核参数：`kptr_restrict=2`、`dmesg_restrict=1`、`yama.ptrace_scope=2`、`unprivileged_bpf_disabled=1`、
  `kernel.kexec_load_disabled=1`、`kernel.unprivileged_userns_clone=0`（按需）、ASLR 强制。
- 模块签名 + 只允许签名模块；`lockdown=integrity/confidentiality`（可用时）。
- 最小化服务：server/desktop/system 各自 systemd preset，禁用未用服务。
- systemd 单元沙箱：`NoNewPrivileges`、`ProtectSystem=strict`、`ProtectHome`、`PrivateTmp`、
  `PrivateDevices`、`RestrictAddressFamilies`、`RestrictNamespaces`、`SystemCallFilter`、`MemoryDenyWriteExecute`。
- AppArmor 默认启用并为 LING OS 服务/应用提供 profile；Landlock 用于用户态应用文件访问限制。
- 资源限制 cgroup v2（沿用现有 app_sandbox_cgroup）。
- 系统完整性：AIDE/自建哈希清单 + 审计。

### 6.3 身份认证与授权
- 用户模型：管理员 / 标准用户 / 访客 / 儿童（可选）；最小 sudo 权限。
- 认证：密码（Argon2id 哈希）+ 可选 TOTP / FIDO2（WebAuthn）/ 恢复码。
- 生物识别：声纹（AI 身份）作为**辅助**认证，不作为唯一因子；模板加密存储（见 6.8）。
- 会话：自动锁屏（可配置）、登录失败锁定、sudo 超时、polkit 细粒度策略。
- 密钥环：系统密钥环 + 用户密钥环；API Key 值级加密（已有 `config_core` 加密占位）。
- VNC：默认仅局域网、随机密码、可配置仅 localhost + SSH 隧道；L3 默认关闭。

### 6.4 磁盘与数据保护
- 安装器默认勾选 **LUKS2 全盘加密**（可关闭但强提示）；加密 swap。
- 解锁方式：密码（默认）/ TPM+PIN（可用时）/ FIDO2（可选）。
- 密钥派生：Argon2id（参数按设备性能自适应，TCG 环境降低时间成本并提示）。
- 用户数据：可选 `systemd-homed`/fscrypt 每用户加密；备份默认加密。
- 安全擦除：crypto-erase（LUKS header 销毁）+ ATA Secure Erase（真机支持时）+ 多次覆写可选。
- 隐私文件：文档元数据清理、EXIF 移除、分享前脱敏。
- 内存保护：mlock 敏感数据、安全清零（已有 secure_memory）、禁用 core dump 含密钥。

### 6.5 应用沙箱与权限
现有资产：`src/security/sandbox/app_sandbox_seccomp.c`、`app_sandbox_cgroup.c`、`app_sandbox.c`，
`permission*.c`、`execution_gate.c`、`access_control.c`。
0.10 改造：
- **bubblewrap/namespace 沙箱**：user/mount/pid/net/ipc/uts/cgroup 命名空间；系统目录只读绑定；
  home 通过 portal 按需访问；`--unshare-net` 默认。
- **权限清单（manifest）**：每个应用声明需要的文件/网络/摄像头/麦克风/位置/通知/剪贴板权限；
  首次运行最小授权；权限使用实时提示（类似 iOS/macOS TCC）。
- **XDG Desktop Portals**：文件选择器、摄像头、麦克风、截屏、位置统一走 portal，杜绝直接设备访问。
- **每应用网络防火墙**：nftables + cgroup 匹配，默认拒绝非白名单应用出站；UI 可一键断网。
- **应用签名与来源**：Flatpak/OCI/.desktop 包签名验证；未知来源默认禁止自动运行。
- **危险能力**：禁止 raw socket、ptrace、挂载、加载内核模块；必要时单独授权。
- **WebUI/App 桥**：沿用权限白名单（`permission_whitelist.c`），高风险操作二次确认。
- **反勒索**：受保护目录（文档/照片）仅授权应用可写（类似 Windows Controlled Folder Access）。

### 6.6 网络与通信安全
- nftables 默认策略：入站 drop、转发 drop、出站放行（L2+ 按应用白名单）。
- 每应用出站控制（cgroup v2 + nftables meta cgroup）。
- DNS：DoT/DoH 默认（可自选 resolver），DNSSEC 校验；禁止明文 DNS 泄漏；DNS 泄漏测试内置。
- MAC 随机化：Wi-Fi/以太网按网络随机；主机名/ DHCP 标识最小化。
- IPv6 隐私扩展开启；关闭 mDNS/LLMNR/UPnP；NTP 使用加密源（NTS 可用时）。
- VPN：WireGuard 内置管理 + **kill switch**（断线阻断全部流量）；分应用分流。
- Tor（可选）：仅对指定应用/流量透明代理；提供桥接配置；默认不强制。
- 远程访问：SSH 仅密钥登录、禁 root、fail2ban；VNC 默认仅 LAN/隧道。
- 浏览器隐私：Firefox 硬化（RFP、uBlock、Cookie 隔离、DNS over HTTPS），默认沙箱运行。
- 通信协议：TLS 1.3 优先、HSTS、证书固定（可选）；聊天/同步若实现则 E2EE（Signal 协议思路）。
- 审计：连接日志默认最小化、按天轮转、可一键清除。

### 6.7 审计、可观测与通知
- 审计日志**哈希链**（每条含前一条 hash），防篡改；关键事件（登录、权限变更、隐私等级切换、
  擦除、更新、AI 云端调用）必记。
- 隐私仪表盘：按应用展示 文件/网络/摄像头/麦克风/位置/剪贴板 访问时间线；可导出/清除。
- 权限使用实时指示：摄像头/麦克风/录屏时顶部常驻图标（桌面 + WebUI）。
- 安全通知中心：与 alertd 集成，分级（信息/警告/严重/生命线）；严重告警不可静默。
- 日志脱敏：传感器原始数据、密钥、Token 不入日志；默认 `loglevel` 与系统一致，可调。

### 6.8 AI 与语音/视觉隐私
- 定位：AI = 管家 + 助手；**隐私优先**。
- 本地优先：默认只调用本地模型（Ollama/本地权重）；云端 Provider 需显式授权且按请求确认；
  L2+ 禁止云端；每次云端调用记录到审计（含发送内容摘要）。
- 记忆：加密存储（SQLite + 字段级加密/文件加密）、可查看/编辑/删除/导出；敏感记忆自动脱敏。
- 声纹：模板在设备端提取，加密存储（TPM/密钥环派生密钥），**永不上传**；可删除/重置；
  身份识别结果只用于个性化与权限辅助。
- 视觉：摄像头帧默认本地处理、不落盘；截图/录像明确提示；L2+ 摄像头默认关闭。
- 指向性识别（0.13）：物体/事件记录本地存储，查询不离开设备。
- Prompt 注入/越权防护：沿用 `rules_ai_guard`，工具调用走权限闸门（`ai_privilege`），高风险二次确认。
- 数据留存：对话/记忆保留策略可配置（30/90/永久）；一键清除。

### 6.9 反取证 / 胁迫 / 极端隐私（L3，GrapheneOS 借鉴）
- **快速擦除**：设置中"紧急擦除"（确认+延时）；胁迫密码触发静默擦除或进入诱饵空间（可选）。
- 自动重启：无操作 N 分钟自动重启到加密锁定状态（可配置，GrapheneOS 同款思路）。
- 锁屏时禁用 USB 数据（USBGuard），仅充电允许。
- 传感器总开关（摄像头/麦克风/GPS/蓝牙/NFC）与硬件级断电（可用时）。
- 截图/录屏保护：敏感应用窗口禁止截屏（Wayland security protocol / portal）。
- 剪贴板：自动清空、禁止后台读取、跨应用粘贴提示。
- 通知隐私：锁屏隐藏内容，仅显示"收到一条通知"。
- 诱饵/多空间（可选）：不同密码进入不同用户空间；隐藏空间加密。
- 网络匿名模式：强制 Tor/VPN + kill switch + 禁用 IPv6 泄漏。
- 反取证：禁用 hibernation、最小化 swap、coredump 关闭、日志可清除但审计链保留摘要。
- 免责声明：极端功能涉及数据丢失风险，必须明确告知并提供恢复路径。

### 6.10 更新与供应链安全
- 更新包签名（minisign/cosign）+ SHA256；安装器/更新器强制校验，失败拒绝安装。
- A/B 原子更新、自动回滚、防降级；更新日志透明化。
- 可复现构建（目标 0.11）：固定依赖、记录工具链、产出 SBOM（SPDX/CycloneDX）。
- 依赖安全：CVE 扫描（Trivy/Grype）、许可证检查、锁版本。
- 构建加固：PIE/RELRO/NX/stack protector/fortify；静态分析 + fuzz 测试（关键解析器）。
- 发布签名与校验说明（用户可自行验证）。
- 密钥管理：发布密钥离线/分级，轮换策略。

### 6.11 恢复与韧性
- 恢复模式：只读救援镜像 → 修复引导/回滚更新/导出日志/重置密码/安全擦除。
- 安全配置错误可恢复：启动失败自动进入恢复菜单（而非黑屏）。
- 备份：系统配置/用户数据加密备份（本地/可选远端），恢复向导。
- 告警链路韧性：网络失败时本地缓存 + 重试 + 明确失败状态（不静默）。
- 安全事件响应流程：检测→隔离→通知→取证（本地日志包）→恢复。

### 6.12 虚拟化 / Vectras 特殊说明
- 宿主 Android/Vectras 在信任边界之外；LING OS 无法保证宿主不窃取数据。
- 共享文件夹默认**只读或不启用**；写入内容按不可信处理；安装/升级时可临时启用。
- VNC 兜底仅绑定局域网，默认随机密码；公网需 VPN/SSH 隧道。
- 无 KMS 时使用 X11/VNC 软件渲染（见 0.9.15 桌面兜底链）。
- 虚拟磁盘加密（LUKS2）在 TCG 下性能可接受；密钥派生参数自动降级并提示。

### 6.13 网络位置（IP 地理定位）与浏览器指纹隐私

> 用户讨论点：用 IP 大致解析地理位置，以及网站/浏览器能获取到的信息。
> 结论：IP 定位仅做“城市级、本地、可关闭、不记录”；浏览器按“默认拒绝 + 指纹最小化”设计；
> 生命线告警（天气/灾害）在定位不可用时必须明确提示，不能静默。

#### 6.13.1 IP 能暴露什么

| 数据 | 来源 | 精度/风险 |
|---|---|---|
| 公网 IP | 任何服务器、CDN、DNS | 可定位到国家/省/城市（通常 50–1000km 误差） |
| ASN/ISP | BGP 路由 | 可识别运营商、企业/家宽/VPN |
| 出口 IP 归属 | GeoIP 数据库 | VPN/Tor/代理会改变“看到的位置” |
| 连接时间/频率 | 服务器日志 | 行为画像、作息推断 |
| 反向 DNS/PTR | 服务商 | 有时暴露组织名或地区 |

关键认知：只要不走代理，网站/ISP 一定能看到 IP；系统能做的不是“隐藏”，而是
**减少系统自身对第三方泄露、限制精度、提供代理/VPN/Tor 通道、并明确告知当前暴露状态**。

#### 6.13.2 LING OS 的 IP 定位规范

1. 离线优先：内置签名 GeoIP 库（候选 DB-IP Lite，CC BY 4.0，可随镜像分发；MaxMind GeoLite2 需注意许可），
   本地查询，默认不调用任何在线 IP 定位 API。
2. 粗粒度：只保存国家/省/城市中心坐标（坐标截断到 2 位小数，约 1km 级别），不保存街道级、
   不保存历史轨迹；每次查询即用即弃。
3. 可关闭/可覆盖：设置里可关闭“IP 粗定位”；用户手动设置城市后永远优先用户设置。
4. 仅授权组件可读：天气、时区建议、灾害预警等系统组件通过本地 D-Bus/Unix socket 获取；
   第三方应用需“位置（粗）”权限。
5. 不记录：位置查询不写审计明文（只记“某组件查询了粗位置”），日志中城市名可脱敏。
6. 代理感知：VPN/Tor 开启时，IP 定位返回出口位置，并在界面标注“（经代理）”，
   避免用户误以为真实位置。
7. 数据库更新：签名 + 哈希校验的离线包，可手动/定时更新（不泄露设备位置）。
8. 降级：无数据库、无网络时，用 /etc/localtime 时区或用户设置作为最粗位置；
   生命线告警场景必须提示“位置为粗略估计”。

#### 6.13.3 浏览器/网站能获取什么（指纹面）

网络层：公网 IP、ASN/ISP、TLS SNI/ALPN、DNS 解析器、HTTP 头、WebRTC 泄露的内网 IP、IPv6 地址。

浏览器层：
- User-Agent、Accept-Language、时区、屏幕分辨率/色深、devicePixelRatio、硬件并发数、设备内存；
- Canvas/WebGL/WebAudio 指纹、字体列表、插件、Math/时区指纹；
- Cookie、localStorage/IndexedDB、缓存、ETag、HSTS 超级 Cookie；
- 媒体设备枚举、电池状态、传感器、游戏手柄、WebGPU、网络信息（effectiveType）；
- 权限 API 探测、剪贴板、通知、地理位置（默认应拒绝）；
- Client Hints（Sec-CH-UA-*，高熵值需权限）；
- 行为指纹（鼠标/键盘节奏、滚动）。

系统层泄露：主机名/DHCP hostname、mDNS/LLMNR/NetBIOS 广播、NTP 请求、IPv6、DNS 明文、
代理绕过、VNC/WebUI 暴露、共享文件夹。

#### 6.13.4 防护设计

系统级：
- 主机名统一为通用值（如 lingos），DHCP 不发送 hostname；关闭 mDNS/LLMNR/NetBIOS；
- MAC 随机化（Wi-Fi 按 SSID 稳定随机，L3 每次连接随机）；IPv6 临时地址 + 禁用 link-local 暴露；
- DNS：DoH/DoT + DNSSEC，阻断明文 53（captive portal 例外）；NTS 时间同步；
- 默认无入站；出站按应用白名单（L2+）；VPN kill switch；Tor 可选；
- WebUI/API 默认仅 localhost，远程访问必须鉴权 + 显式开启。

浏览器级（默认 Firefox 硬化策略）：
- privacy.resistFingerprinting=true、privacy.globalprivacycontrol.enabled=true；
- WebRTC：默认禁用或仅代理模式（media.peerconnection.enabled=false / ice 策略）；
- Canvas/WebGL：默认不屏蔽（兼容性），提供“强隐私浏览”开关做随机化；
- 电池/传感器/游戏手柄/媒体设备枚举默认关闭；
- Cookie：Total Cookie Protection + 第三方 Cookie 默认阻止；缓存/站点数据按站点隔离；
- DoH 强制；Referer 跨域裁剪；查询参数剥离（query stripping）；
- uBlock Origin 等拦截器可选（不预装名单，用户自选源）；
- 地理位置权限默认拒绝；浏览器运行在沙箱（Flatpak/firejail/bubblewrap）。

验证工具（内置到诊断/隐私面板）：
- IP 暴露检测（当前出口 IP/ASN/城市粗定位 + 是否经代理）；
- DNS 泄漏测试、WebRTC 泄漏测试、IPv6 泄漏测试；
- 浏览器指纹自检（Canvas/WebGL/时区/字体/UA 概览）；
- “网站能看到的我”报告页（本机视角，不上传）。

#### 6.13.5 生命线场景（天气/灾害预警）的定位策略
1. 优先级：用户手动设置城市 > 最近一次用户确认的粗位置 > IP 粗定位 > 时区；
2. 任何一级降级都在 UI 明确标注（如“位置：北京（IP 粗定位，误差约 50km）”）；
3. 告警失败/定位不可用必须显示“无法确定位置，请手动设置”，不得显示“平安”；
4. 天气/预警请求只发送城市级坐标/城市名，不发送精确坐标；
5. 第三方天气 Provider 需在隐私面板列出（域名、发送字段、频率）。

#### 6.13.6 新增威胁（补充第 2 节）
- 广告商/网站通过 IP + 浏览器指纹跨站识别用户；
- ISP/公共 Wi-Fi 通过 DNS/SNI 推断访问内容；
- WebRTC/内网 IP 泄露暴露局域网结构；
- 恶意应用读取系统粗位置推断用户住址；
- VPN/Tor 出口被误认为真实位置导致告警/天气错误。


### 6.14 可选项、自定义模式与 L4（MAX）隐私保护

#### 6.14.1 立场
- 不替用户做“是否需要这些”的决定：所有隐私/安全增强都做成**可选开关**，默认值明确；
- 每个开关都必须标注“可能影响哪些网站/应用/功能 + 如何恢复”，避免用户因隐私过严导致网站不可用却不知道原因；
- 提供“兼容性诊断 + 单点临时放宽”（仅在本地确认后生效）；
- 新增 Custom 自定义模式与 L4（MAX）最高保护档。

#### 6.14.2 选项清单（示例，完整清单随 UI 发布）

| 选项 | 默认（L1） | 开启/关闭可能影响 |
|---|---|---|
| IP 粗定位（城市级） | 开 | 关闭后天气/预警需手动设置城市 |
| 精确位置/GPS | 关（无硬件时不可用） | 地图/导航/跑步类应用不可用 |
| 浏览器地理位置权限 | 拒绝 | 网站“附近门店/定位”功能不可用 |
| 第三方 Cookie | 阻止 | 部分登录/支付/嵌入内容异常 |
| Canvas/WebGL 随机化 | 关（强隐私开） | 在线绘图、部分游戏/地图可能异常 |
| WebRTC | 限制/关闭 | 网页视频会议可能连不上 |
| DoH/DoT 加密 DNS | 开 | 部分校园网/企业网可能无法解析 |
| VPN / Tor | 关（可选） | 开启后局域网设备/打印机可能不可达 |
| 摄像头/麦克风/传感器 | 默认关或按应用 | 相关应用需授权后才可用 |
| 剪贴板保护 | 开 | 跨应用粘贴需确认 |
| 云 AI（DeepSeek 等） | 关 | 仅本地模型可用，能力受本地算力限制 |
| 遥测/分析上报 | 关 | 不影响功能 |
| MAC 随机化/主机名隐藏 | 开 | 企业网络准入（802.1X/绑定 MAC）可能异常 |
| VNC 远程桌面 | 关 | 无图形时需手动开启局域网 VNC |
| 后台同步/自动联网更新 | L4 关，其余可配 | 关闭后需手动更新/同步 |

每个选项的 UI 必须包含：说明、影响范围、兼容性测试入口、恢复默认按钮。

#### 6.14.3 自定义模式（Custom）
- 用户逐项选择：隐藏 / 允许 / 按应用 / 按网站 / 仅本次 / 本次会话 / 永久；
- 支持按站点规则（如“允许银行网站 Cookie，其余全禁”）与按应用规则；
- 配置可导出/导入（仅本地加密文件）；支持“恢复推荐默认”“恢复隐私优先”两套预设；
- 兼容性诊断：列出因当前设置失败的网站/应用，并给出“只放宽这一项”的建议。

#### 6.14.4 L4（MAX）最高隐私保护
定义：**默认全拒绝（deny-all）**；任何数据获取都必须先经用户手动确认，并且由用户手动指定可获取范围；**未明确授权的范围一律禁止（默认禁止范围=全部）**。

- 网络：默认无出站（仅本地回环）；任何应用/网站联网需授权，授权包含域名/端口/协议/目的/时长；
- 权限：摄像头/麦克风/位置/屏幕/剪贴板/文件/通讯录/传感器/通知全部默认拒绝，逐次确认；
- 数据获取：所有请求进入“请求审批中心”，展示请求方、数据类型、范围、用途、风险；用户可选拒绝 / 仅本次 / 本次会话 / 永久 / 限定范围；
- 网站：默认不暴露任何设备信息（指纹面最小化），Cookie/存储默认禁用，按站点授权；
- 系统：关闭后台同步、自动联网更新、云 AI、遥测、VNC、远程访问；只保留本地功能（离线 AI、本地文件、离线帮助）；
- 审批记录：全部写入审计哈希链，可查看/导出；清除仅限本地；
- 兼容性警告：L4 会导致大量网站/应用不可用；提供逐项放宽路径，但每次放宽都需本地确认并记录；
- 紧急恢复：L4 下保留本地控制台与恢复模式；若设置导致无法操作，可本地重置到 L2 并保留审计。

#### 6.14.5 安全/隐私设置只能本地修改（防远程、防模拟点击）
目标：防止局域网远程通道、WebUI/App/API、VNC/SSH，以及自动化/模拟点击修改安全策略。

1. **唯一入口**：本地物理控制台会话（seat0、Session.Remote=no、Type∈{tty,wayland,x11} 的本地会话）运行的安全设置应用；VNC/SSH/远程 WebUI 一律只读。
2. **服务端强制**：安全策略写入仅接受本机特定 Unix socket + 本地会话凭据/TPM 封印；HTTP/D-Bus/WebSocket 不暴露“修改安全设置”方法；远程请求返回 403 并写审计。
3. **本地再认证**：进入设置需本地密码 + 可选 FIDO2/声纹辅助；修改 L2+ 需**键入确认短语**（不是单击确认）。
4. **输入注入防护**：安全设置窗口禁止 XTEST/uinput/ydotool/RemoteDesktop portal 注入；检测到自动化工具或远程会话时禁用修改；Wayland 下用安全协议禁止合成输入。
5. **配置完整性**：策略文件签名/哈希，只有本地特权守护进程可写；任何修改生成审计事件；回滚需本地恢复模式。
6. **明确告知**：UI 标注“安全设置仅可在此设备本地修改”。

#### 6.14.6 配置权限矩阵

| 通道 | 查看状态 | 修改安全/隐私设置 |
|---|---|---|
| 本地控制台（seat0、Remote=no） | 是 | 是（需再认证 + 键入确认短语） |
| 本地桌面应用（本地会话） | 是 | 仅通过系统“安全设置”应用 |
| WebUI（局域网） | 只读摘要 | 否（403 + 审计） |
| App（远程） | 只读摘要 | 否 |
| VNC | 只读摘要 | 否 |
| SSH | 只读摘要 | 否 |
| API/自动化/脚本 | 只读 | 否（403 + 审计） |
| 恢复模式（本地） | 是 | 重置/回滚（需物理确认） |

#### 6.14.7 新增威胁
- 局域网攻击者通过 WebUI/API 降低隐私设置；
- 恶意网页/应用通过 clickjacking/模拟点击诱导放宽权限；
- 自动化脚本批量修改安全策略；
- 远程 VNC/SSH 会话冒充本地控制台。

#### 6.14.8 验收标准
- 远程通道尝试修改设置全部失败且留审计；
- 模拟点击/自动化修改被阻止；
- L4 下默认无出站、所有访问需审批且范围可由用户限定；
- 自定义模式逐项生效、兼容性诊断准确；
- 安全设置从本地控制台可正常修改（再认证 + 确认短语）。

## 13. 风险与待确认问题

1. **硬件限制**：无 TPM/Secure Boot 自定义密钥时，验证启动只能做到"软件信任根"；是否接受？
2. **性能**：TCG/低端 arm64 上 LUKS2 + Argon2id 首启耗时；是否允许自动降参并提示？
3. **L3 极端档**：胁迫擦除/诱饵空间涉及数据丢失与法律风险，是否默认关闭、仅高级用户开启？
4. **Tor 是否内置**：内置会增大维护与合规风险；建议"可选组件"而非默认。
5. **FDE 默认**：是否所有 edition 默认强制加密？server 无头设备如何解锁（TPM/网络解锁/密钥文件）？
6. **AI 云服务**：是否允许用户自配 Provider（DeepSeek 等）？默认仅本地是否满足功能预期？
7. **共享文件夹/VNC**：Vectras 场景是否默认关闭共享文件夹？VNC 是否要求设置密码才能启用？
8. **法规/合规**：隐私政策、数据处理协议、出口/加密合规是否需要法务评审？

## 16. 补充校准（2026-10-30 续）：GrapheneOS 精确对照、分级信任与 AI 工具限制

### 16.1 先纠正：GrapheneOS 实际有什么（避免夸大）

用户提醒正确：此前把一部分“通用隐私最佳实践”也算进了 GrapheneOS。现按官方特性重新校准。
GrapheneOS 是 **Android 强化系统**，能力边界与 Linux 发行版不同；我们借鉴其设计哲学，不逐条照抄。

| GrapheneOS 官方特性 | 说明 | LING OS 可复刻程度 |
|---|---|---|
| 验证启动 + 自定义 AVB 密钥 + 回滚保护 | 用户自签、重锁 bootloader | 高：dm-verity + 签名 GRUB/内核 + A/B 防回滚（0.11） |
| 硬件证明（Auditor） | TPM/硬件密钥远程证明 | 低：多数设备无 TPM，0.14 可选 |
| hardened_malloc / MTE / 内核加固 / CFI | 内存安全与漏洞利用缓解 | 部分：加固编译/ASLR/seccomp；MTE 无 |
| 沙箱化 Google Play | 特权服务降权运行 | 无 GMS；等价：应用沙箱（0.10） |
| 每应用网络权限（INTERNET 可撤销） | 默认拒绝、可撤销 | 高：nftables 每应用出站（0.10） |
| 每应用传感器权限 | 摄像头/麦克风等 | 高：XDG portal 权限（0.10） |
| 存储范围 / 照片选择器 | 按文件范围授权 | 高：portal 文件范围（0.10） |
| 权限自动重置 | 长期未用自动收回 | 高：0.12 |
| MAC 随机化（每连接） | Wi-Fi/蓝牙隐私 | 高：NetworkManager 随机 MAC（0.10） |
| 自动重启 / PIN 混淆 / 锁屏禁 USB | 防取证 | 高：0.12（L3） |
| 多用户 / Private Space | 隔离空间 | 中：多用户/诱饵空间（0.12 可选） |
| Duress PIN/password | 较新版本有限支持（擦除/切换用户） | 中：0.12 可选，需标注版本差异 |
| Vanadium 硬化浏览器 | WebView/浏览器加固 | 中：Firefox 硬化（0.10） |
| Private DNS（DoT） | 加密 DNS | 高：DoH/DoT（0.10） |
| 无遥测 / 无预装 Google | 隐私默认 | 高：默认无遥测（0.10） |
| 通知隐私 / 摄像头麦克风指示 / 剪贴板提示 | 隐私提示 | 高：0.10 |
| 快速签名更新 | 更新安全 | 高：0.11 |
| 攻击面缩减（锁屏禁 NFC/蓝牙等） | 默认关闭不必要能力 | 高：0.12 |

**GrapheneOS 没有、不应归入其特性的**（此前可能混淆）：
内置 Tor、硬件断电式传感器开关、完整诱饵系统/双系统、全系统截图保护、
桌面式应用防火墙 UI、任意 Linux 软件运行（它是 Android）。

结论：借鉴“默认拒绝、最小权限、可验证、可撤销、可审计”的哲学；
具体实现按 LING OS 的 Linux/桌面形态落地。

### 16.2 分级信任模型（按 L0–L4）

信任对象：网络、位置、设备/USB、应用来源、文件/共享文件夹、AI 工具、插件、远程访问。

| 对象 | L0 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|---|
| 网络 | 自动连接开放网络 | 仅受信网络自动连接 | 受信白名单 + 非受信强制 VPN | 仅 VPN/Tor，无自动连接 | 全部不信任，逐次审批（域名/端口/时长） |
| 受信位置 | 不启用 | 可标注家/公司（仅便利功能） | 使用前需确认一次 | 不使用位置信任 | 不采集位置 |
| USB/外设 | 允许 | 新设备需确认 | 数据默认禁，仅充电 | 锁屏禁 USB，解锁需确认 | 默认禁，逐次审批 |
| 应用来源 | 任意（警告） | 签名或确认 | 仅签名/商店 | 白名单 | 逐次审批 + 范围 |
| 文件/共享文件夹 | 可写 | 只读 + 扫描 | 禁用或只读 | 禁用 | 禁用 |
| AI 工具 | 常用工具自动 | 写/网络需确认 | 本地只读自动，写逐次 | 全部逐次 + 范围 | 全部逐次 + 范围 + 时限 |
| 插件 | 可装 + 授权 | 签名 + 沙箱 | 默认禁用 | 禁止 | 禁止（或逐次） |
| 远程访问 | VNC 可开 | VNC 仅 LAN + 密码 | 默认关，需本地开 | 禁止 | 禁止 |

规则：
1. “受信”必须由用户手动定义：SSID+BSSID 哈希、模糊到约 500m 的位置、设备指纹；禁止自动学习后静默信任。
2. 信任等级升降必须本地确认（L2+），并写审计。
3. L4 无任何“自动信任”；每一次网络/设备/文件访问都要审批并指定范围。
4. 受信位置只用于便利功能（自动挂载备份盘、自动连接受信网络），不用于绕过安全。
5. 位置数据：L0–L1 城市粗定位；L2 仅手动设置；L3/L4 不采集。
6. 生命线告警仍按 6.13.5 优先级；L4 下必须用户手动设置位置。

### 16.3 AI 工具与插件限制（按等级）

工具注册表 manifest 字段：id、name、描述、capabilities（read/write/exec/network/device/account）、
data_scope、risk_level、confirmation_policy、rate_limit、audit。

| 等级 | AI 工具策略 |
|---|---|
| L0 | 只读工具自动；写/网络单次确认 |
| L1 | 本地只读自动；写/网络/设备确认；禁止后台代理循环 |
| L2 | 仅本地白名单工具自动；写/网络逐次确认；禁止长期托管 |
| L3 | 全部逐次确认 + 范围 + 时长；禁止后台代理 |
| L4 | 全部逐次确认 + 用户手动范围 + 时限；禁止自动批准；禁止插件工具 |

硬规则：
1. AI 不得修改安全/隐私设置（任何工具都不允许）。
2. AI 不得读取密钥、凭据、生物特征模板。
3. 每次工具调用必须声明“目的 + 范围”，越权直接拒绝并审计。
4. 高风险操作（exec/网络/删除/支付）必须本地确认；L3/L4 需键入确认短语。
5. 工具结果写入记忆前必须脱敏。

插件限制：
1. 仅允许签名插件，manifest 声明权限；默认无网络/文件/设备。
2. 运行在沙箱（seccomp + namespace + cgroup），资源限额。
3. 按等级授权；L2+ 默认禁用；L4 禁止。
4. 插件禁止调用安全设置/系统 API，禁止注入桌面/AI 会话。
5. 插件市场审核 + 本地白名单 + 一键禁用/卸载 + 审计。
